# Reference library

This directory records sources used by the project without copying material whose
licence or redistribution terms have not been verified. The local course PDFs and
the Hull textbook supplied by the project owner remain outside the repository.

`provenance.csv` is the authoritative source ledger. Before adding a downloaded
source, record its stable URL or DOI, access status, permitted use, download date,
and SHA-256 hash. Do not add pirated, paywalled, or rights-uncertain copies.

theorems, proofs, proof sketches, and numerical evidence.
